# 2. Transaction Creation API

Create a secure REST API endpoint using CodeIgniter 4.

## Endpoint Example

POST `/api/v1/transaction/create`

## Request Payload

```json
{
  "business_id": "BUS_001",
  "email": "user@example.com",
  "amount": 5000
}
```

## Functional Requirements

- Validate API credentials
- Validate business exists
- Validate amount
- Generate unique transaction ID
- Add randomized kobo value for payment verification (after deducting 1 naira)
- Save original amount and randomized payable amount
- Save registration JSON data
- Generate unique registration ID
- Set initial transaction status as `pending`

## Response Example

```json
{
  "status": true,
  "transaction_id": "TXN_ABC123",
  "original_amount": 5000,
  "payable_amount": 4999.37,
  "currency": "NGN",
  "message": "Transaction created successfully",
  "business_id": "BUS_01"
}
```

# 3. Transaction Status Polling API

Create a dedicated endpoint for frontend polling.

## Endpoint Example

GET `/api/v1/transaction/status/{transaction_id}`

This endpoint will be polled every 5 seconds by frontend applications.

## Response Example

```json
{
  "status": true,
  "transaction_id": "TXN_ABC123",
  "payment_status": "success",
  "amount_paid": 4999.37,
  "business_id": "BUS_01"
}
```

Possible statuses:

- pending
- success
- failed
- expired

# 4. Payment Webhook System

Create a secure webhook endpoint to receive payment gateway callbacks.

## Endpoint Example

POST `/api/v1/webhook/payment`

## Requirements

- Verify webhook authenticity using a unique signature
- Signature verification must use HMAC SHA256
- Reject invalid webhook requests
- Validate transaction exists
- Match payment amount including randomized kobo
- Update transaction status to `success`
- Save webhook payload logs
- Prevent duplicate webhook processing

## Example Signature Header

```http
X-Payment-Signature: HASH_SIGNATURE
```

## Webhook Validation Logic

- Use business webhook secret key
- Hash request payload
- Compare computed signature against incoming signature header
- Only process verified requests
